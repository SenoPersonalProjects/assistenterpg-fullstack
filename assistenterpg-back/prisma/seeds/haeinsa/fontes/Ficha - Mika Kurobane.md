# FICHA NPC — MIKA KUROBANE — A CORTINA

**Função:** controle de linha de visão / extração  
**Tamanho:** Normal

| Atributos | Valores |
|---|---|
| AGI / FOR / INT / PRE / VIG | **4 / 1 / 3 / 3 / 2** |
| PV / EA | **105 / 60** |
| Defesa / RD | **25 / 3** |
| Movimento | **9m** |

**Resistências:** Fortitude **2d20+11**; Reflexos **4d20+16**; Vontade **3d20+13**.  
**Combate:** Iniciativa **4d20+16**; Percepção **3d20+13**; Jujutsu **3d20+15**.

## Defesa rápida

**Reação Especial:** **1/rodada** — Esquivar, Bloquear ou Contra-atacar.

- **Esquiva:** **41**.
- **Bloqueio:** **14 RD** contra a ocorrência.
- **Contra-ataque:** se houver alvo válido para o leque, use **4d20+14; 2d6+5 Corte**.
- **Cai o Pano** é **Reação comum** e não consome a Reação Especial.

# Técnica Amaldiçoada — Cortina de Funeral

Cada biombo tem **30 PV, DEF 18, RD 5**, cerca de 3m × 2,5m. Bloqueia visão e ataques que exigem linha direta, mas não impede automaticamente áreas ou efeitos que atravessem obstáculos. **Máximo 3 biombos persistentes ativos**; criar outro acima do limite dissolve o mais antigo.

## Erguer Biombo
**Padrão — 2 EA — curto.** Cria 1 biombo persistente em ponto válido.

## Corredor de Cortinas
**Completa — 6 EA.** Cria até 3 biombos persistentes em pontos distintos em alcance curto.

## Leque Cortante
**Padrão.** 4d20+14; **2d6+5 Corte**.

## Fechar Sobre o Alvo
**Padrão — 3 EA.** Reflexos **DT 26**. Falha: **3d8+5 Impacto + Imóvel** até gastar Movimento para sair. Os painéis usados para prensar o alvo são **momentâneos** e se desfazem depois da resolução; não entram no limite dos 3 biombos persistentes.

## Cai o Pano
**Reação comum — 3 EA — 1/rodada.** Quando aliado em curto vira alvo de ataque cuja origem Mika percebe, cria biombo entre atacante e alvo. Se exigir linha de visão, o biombo passa a ser o obstáculo. O biombo criado conta no máximo de 3 ativos; se exceder, dissolve o mais antigo. **Não consome a Reação Especial.**

# Operação

Mika começa com **Marca de Cúmplice**. Sua prioridade é criar a janela de Ato Cego, não vencer Takaramono em troca frontal.

### Turno de consulta rápida
1. **Posicione ou crie biombos** para quebrar a observação de Takaramono.
2. Preserve Movimento para reposicionar Mika se a linha de visão mudar.
3. Quando um ataque importante ameaçar um aliado, **Cai o Pano** pode reagir sem gastar a Reação Especial.
4. Guarde a Reação Especial para **Esquiva/Bloqueio** quando Mika for pressionada diretamente.
